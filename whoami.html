What This Site Can See About You

This page shows — in plain language — every piece of information a website can collect about a visitor using nothing but standard browser and network features. Nothing below required a permission prompt (no camera, microphone, or precise GPS access), and nothing is hidden from you: it's the same data this analytics tool would record if it were tracking you for real.

Why this looks like so much: every website you visit can see most of this already — it's built into how browsers make requests. This tool just makes it visible instead of invisible. See README.md for exactly what's stored, for how long, and how to opt out.
